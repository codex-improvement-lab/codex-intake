# Codex Intake design direction — Proofing Press

## Product feeling

Codex Intake turns a messy desk into a working contract. It should feel tactile, constructive, and visibly local—more like a proofing table than a form wizard.

## Visual grammar

- Paper and ink establish the workbench.
- Coral marks action, acid marks readiness, cobalt marks provenance.
- Offset shadows and indexed source cards make digital material feel handleable.
- Editable text remains visually distinct from deterministic, source-linked signals.

## Signature interaction

The **Provenance Lens** begins from the explicit **Trace links** control on a real source card or from any stored pointer. It highlights every brief signal linked to that source and dims unrelated material, making the transformation from messy input to task contract inspectable in one gesture.

## Guardrails

- Never fetch registered URLs silently.
- Never invent a pointer or imply that deterministic extraction is model judgment.
- Manual fields keep their `USER` ownership and are not falsely traced to an input.

## Acceptance

A user can select any source and immediately see exactly what that source contributed to the generated brief.
